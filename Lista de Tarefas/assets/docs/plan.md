# Projeto: To-do list simples com HTML, CSS e Javascript

Este será um projeto de tela unica, em que na parte superrio teremos um campo de texto para adicionar uma tarefa nova e um botao de envio

Ao enviar a tarefa, ela sera adicionada a uma lista exbida logo abaixo desse campo de texto.

As tarefas serão armazenadas em um array no próprio javascript, sem uso de nenhuma ferramenta ou  sistema externo.

cada tarefa precisa ter:
- texto
- boolean confirmando se esta feita ou não

Sobre as ações possiveis em cada tarefa:
-Marcar/desmarcar ela como concluida, dai o texto fica riscado (via classe css)
-Deletar uma tarefa. então ela some da lista completamente.
-Adicionar uma trarefa nova através do campo de texto na parte superior da tela e sera sempre adionanda com o boolean de confirmação em false.

o projeto será feito utilizando HTML, CSS E Javascrip simples.

No javascript, trabalhar sempre com Eventlisteners e não adicionando eventos no HTML diretamente.
No ínicio do Javascript, já selecione em variaveis todos os elementos que serão manipulados.

Interface gráfica:

- o fundo do projeto sera em cinza claro.
- Tando o campo quanto a lista ficarão me cards separados, com fundo branco, borda arredondada e uma leve separação entre os cards.
- A cor predominando para os botões (como o botão de adicionar e deletar) será verde militar
