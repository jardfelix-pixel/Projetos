# Projeto: Interface IA Chat - Jarvis-JFELIX

O projeto é uma interface inicial de chat com IA, semelhante a página do ChatGPT, Claude, Grok e etc.

## Aspectos visuais
A tela deve ser escura(dark) e o campo de busca no meio da tela.

O tema principal do projeto é em tom de azul marinho.

Dentro da área do campo de busca deve ter também:
- Na parte inferior esquerda:
  -- Botão (que ativa/desativa) dizendo "Pensamento profundo"
  -- Botão (que ativa/desativa) dizendo "Pesquisa Inteligente"
- Na parte inferior direita:
  -- Botão de enviar, arredondado

Acima da área do campo de busca deve ter 3 opções (como tabs) para selecionar:
- Rápido
- Especialista

Acima deles, o nome do projeto: Jarvis de JFELIX

## Aspectos técnicos

O projeto usa Vite + React + Typescript + Tailwind

O projeto deve usar componentes na pasta src/components, devidamente organizados e sem repetir componente desnecessáriamente.

Por hora não há nenhuma ação de busca.
